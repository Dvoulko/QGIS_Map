# QGIS_Map
Χωρική ανάλυση και αποτύπωση ελεύθερων χώρων πρασίνου, υποδομών στάθμευσης και δικτύων ΜΜΜ στο κέντρο της Θεσσαλονίκης με τη χρήση QGIS. Εστίαση στη Βιώσιμη Αστική Κινητικότητα (ΣΒΑΚ) και την αντιμετώπιση της Αστικής Νησίδας Θερμότητας.
